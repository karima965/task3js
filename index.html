Understanding Events in JavaScript

onclick

The onclick event is written directly inside the HTML element.
It is simple but mixes JavaScript with HTML

VS

addEventListener()

The addEventListener() method attaches events in JavaScript.
It is more powerful, flexible, and keeps code clean and organized.

Why preferred? addEventListener() allows multiple events on the same element and separates JavaScript from HTML.
which is best practice in modern web development.
